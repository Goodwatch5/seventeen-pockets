# Seventeen Pockets Automation System

Production-grade distributed infrastructure automation with React, Supabase, and pocket converter.

## Quick Start

```bash
cd automation
npm install
cp .env.example .env.local
npm run dev
```

## Features

* Auto-deploy ready pockets
* Health monitoring
* Real-time metrics
* Export to JSON/CSV
* Pocket status transitions
* Responsive design
