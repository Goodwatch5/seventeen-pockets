# Seventeen Pockets / Rightway

Seventeen Pockets / Rightway is a multi-project ecosystem composed of specialized projects that represent different operational forms of the same platform.

The platform is organized as one coordinated system across interface, orchestration, data, collaboration, and AI.

**One platform. Multiple operational forms. Unified by design.**

***

## Overview

Rightway is the ecosystem home: the central documentation and coordination repository for the broader Seventeen Pockets / Rightway system.

The platform currently includes:

* a frontend interface layer
* a backend orchestration layer
* a data and metrics layer
* a collaboration layer
* affiliated external intelligence services

***

## Operational forms

| Operational form   | Purpose                                   |
| ------------------ | ----------------------------------------- |
| Frontend form      | Dashboard, interface, user experience     |
| Backend form       | APIs, orchestration, service coordination |
| Data form          | Metrics, collection, system intelligence  |
| Collaboration form | Team coordination and workflow support    |
| AI form            | Intelligence and agent-based services     |

## Architecture summary

```
Rightway Dashboard
├── seventeen-pockets API
├── solar-connect
└── nextmyteam
    └── deepagent
```

High-level flow:

```
User interaction begins in Rightway
→ Rightway requests and displays platform data
→ seventeen-pockets coordinates backend services and logic
→ solar-connect provides metrics and system intelligence
→ nextmyteam contributes collaboration and workflow functionality
→ deepagent provides affiliated intelligence services
```

Full detail is in [docs/architecture.md](docs/architecture.md).
