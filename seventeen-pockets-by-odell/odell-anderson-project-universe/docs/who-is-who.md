# Who’s Who

This page defines the main identities and roles within the Seventeen Pockets / Rightway ecosystem.

***

## Platform identity

### **Seventeen Pockets / Rightway**

**Role:** Unified platform identity

Seventeen Pockets / Rightway is the system-level identity of the ecosystem. It is the umbrella platform under which the specialized project forms operate.

***

## Core operational forms

### **Rightway**

**Project ID:** `76967613`\
**Role:** Frontend / interface form

Rightway is the main user-facing layer of the platform and the ecosystem home repository.

### **seventeen-pockets**

**Project ID:** `76506056`\
**Role:** Backend / orchestration form

seventeen-pockets provides core API services, backend logic, and orchestration across connected platform functions.

### **solar-connect**

**Project ID:** `76887018`\
**Role:** Data / metrics form

solar-connect provides connected data collection, metrics, and operational insight.

### **nextmyteam**

**Project ID:** `76117871`\
**Role:** Collaboration form

nextmyteam provides the collaboration and workflow-support layer of the platform.

***

## Integrated external service

### **deepagent**

**Project ID:** `76277290`\
**Role:** AI / intelligence form

deepagent is an affiliated intelligence service integrated into the broader ecosystem architecture.

***

## System relationship

* **Rightway** provides the interface
* **seventeen-pockets** provides orchestration
* **solar-connect** provides data and metrics
* **nextmyteam** provides collaboration
* **deepagent** provides affiliated intelligence services
