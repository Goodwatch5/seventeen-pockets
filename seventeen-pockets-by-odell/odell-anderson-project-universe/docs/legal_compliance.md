# Legal Compliance & Branding Guidelines

**Last Updated:** 2025-12-29

## Organization Identity

**Official Branding:**

* Branded by ODell
* Powered by ODell and Light Creations
* Seventeen Pockets Brand

## Critical Legal Requirements

All projects in this ecosystem must comply with the following:

### 1. Platform Ownership Disclaimer

Every project README must include:

```markdown
## Platform Disclaimer

This project is hosted on GitLab and/or GitHub. We do not own, operate, or control GitLab, GitHub, or any Git-related infrastructure. These are third-party services we utilize for version control and collaboration.
```

### 2. Prohibited Naming Conventions

**DO NOT USE:**

* "Git Company"
* "Git Systems"
* "Git Labs"
* "Git Collective"
* "Git Studios"
* Any name implying ownership of Git, GitHub, or GitLab

**USE INSTEAD:**

* Project names that reflect actual purpose/function
* Brand names: ODell, Light Creations, Seventeen Pockets
* Descriptive names: \[function]-\[purpose]

### 3. Copyright & License

All projects must have:

* Clear copyright holder (ODell Anderson or appropriate entity)
* Proper open source license (MIT, Apache 2.0, etc.)
* No claims of platform ownership

### 4. Documentation Standards

Every README.md must include:

```markdown
# [Project Name]

**Part of the ODell Ecosystem**

[Project description]

## Platform Disclaimer

This project is hosted on GitLab/GitHub. We do not own, operate, or control these platforms.

## License

[License type] - See LICENSE file for details
```

### 5. Governance Files

Governance and organizational files must:

* Clarify actual organizational structure
* Not imply ownership of platforms or infrastructure
* Reference this compliance document
* Include proper attribution

## Audit Checklist

For each project, verify:

* [ ] README.md includes platform disclaimer
* [ ] No "Git Company" or similar naming
* [ ] Copyright holder is clearly stated
* [ ] License file exists and is correct
* [ ] No claims of platform ownership
* [ ] Branding reflects ODell/Light Creations/Seventeen Pockets
* [ ] CONTRIBUTING.md (if exists) includes disclaimer
* [ ] governance files (if exists) are compliant

## Enforcement

All pull requests must:

1. Include platform disclaimer in new documentation
2. Remove any non-compliant naming or claims
3. Reference this document in commit messages
4. Pass legal compliance review
