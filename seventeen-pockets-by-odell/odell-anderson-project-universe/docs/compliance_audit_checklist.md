## Compliance Checklist (Per Project)

### README.md

* [ ] Includes project name/title
* [ ] Includes "Part of ODell Ecosystem" or similar
* [ ] Includes platform disclaimer
* [ ] No "Git Company", "Git Systems", etc.
* [ ] Clear project description
* [ ] License information present

### License File

* [ ] LICENSE file exists
* [ ] Copyright holder is correct (ODell Anderson or entity)
* [ ] License type is appropriate
* [ ] No platform ownership claims

### Governance/Org Files (if applicable)

* [ ] No "Git Company" naming
* [ ] Clarifies actual organizational structure
* [ ] Includes platform disclaimer
* [ ] References LEGAL\_COMPLIANCE.md

### Documentation

* [ ] CONTRIBUTING.md (if exists) is compliant
* [ ] CODE\_OF\_CONDUCT.md (if exists) is compliant
* [ ] governance/ files (if exists) are compliant
* [ ] No misleading branding

### Code/Config Files

* [ ] .github/workflows/ files don't claim platform ownership
* [ ] .gitlab-ci.yml doesn't claim platform ownership
* [ ] package.json/setup.py don't claim platform ownership
