# Deployment Truth

This page defines the clearest current deployment interpretation for the Seventeen Pockets / Rightway ecosystem.

***

## Canonical source of truth

**Rightway on GitLab is the documentation and coordination center of the platform.**

For this repository, the most authoritative platform deployment signals are:

* `.gitlab-ci.yml` for GitLab CI/CD behavior
* `docs/DEPLOYMENT_GUIDE.md` for broader operational intent
* `docker-compose.yml` for local or container-based orchestration intent
* `netlify.toml` for Netlify-specific frontend deployment behavior

***

## Current practical interpretation

The ecosystem currently shows multiple deployment paths, but they do not all carry the same weight.

### 1. Documentation truth

The canonical documentation home is **Rightway**.

This repository should be treated as the platform's primary source of truth for:

* ecosystem structure
* project relationships
* architecture
* current state
* deployment interpretation

### 2. CI/CD truth

GitLab CI/CD is the clearest active automation path visible in this repository.

The repository includes:

* `.gitlab-ci.yml`
* local CI includes under `.gitlab/ci/`
* pipeline stages for validation, deep logic, build, and deploy

This makes GitLab CI/CD the strongest operational automation signal in the current repository state.

### 3. Frontend deployment truth

`netlify.toml` indicates that Netlify is configured as a frontend deployment target for Rightway. The canonical frontend build output is `dist/` (generated by `npm run build`).

That means Netlify should be described as a **configured frontend deployment target**, not as the sole platform source of truth.

### 4. Local orchestration truth

`docker-compose.yml` shows a broader service orchestration model for local or containerized execution.

This should be interpreted as:

* a platform operations model
* a local or infrastructure-oriented deployment path
* not the primary documentation center

***

## Recommended canonical wording

Use this wording consistently:

> **Rightway is the ecosystem home and documentation source of truth. GitLab CI/CD is the primary visible automation path in this repository. Netlify is a configured frontend deployment target. Docker Compose reflects broader service orchestration intent.**

***

## What this means operationally

When describing the platform, use this order of authority:

1. **Rightway documentation** — system truth and architecture truth
2. **GitLab CI/CD** — automation and pipeline truth
3. **Netlify** — frontend publishing target
4. **Docker Compose / broader deployment docs** — infrastructure and orchestration model

***

## What to avoid

Avoid presenting every deployment file as equally authoritative. That creates confusion.

Do not say:

* the platform has one single deployment path if multiple paths are still configured
* Netlify alone defines the platform
* Docker Compose alone defines production truth

Instead, distinguish:

* documentation truth
* automation truth
* frontend deployment target
* orchestration model

***

## Current platform answer

If someone asks, “Where does this platform live and how does it deploy?” the clearest answer is:

> **The Seventeen Pockets / Rightway platform is documented centrally in Rightway. Its clearest active automation path is GitLab CI/CD. It also includes Netlify configuration for frontend deployment and Docker Compose for broader orchestration intent.**

***

## Platform principle

**One platform. Multiple operational forms. Unified by design.**
