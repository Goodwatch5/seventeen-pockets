# Ecosystem Stabilization Baseline

This repository is part of the Seventeen Pockets ecosystem stabilization pass.

## Immediate operating standard

* Keep default branch deployable.
* Prefer merge requests over direct commits when credits/time allow.
* Preserve existing project-specific CI unless a targeted fix is required.
* Add governance/compliance modules through controlled branches.
* Do not commit secrets, tokens, PHI, or raw patient records.

## Stabilization checklist

* [ ] CI pipeline is syntactically valid.
* [ ] Install command is documented.
* [ ] Test command is documented or safely skipped when no tests exist.
* [ ] License file exists.
* [ ] Governance/compliance files are present where applicable.
* [ ] Deployment path is documented.
