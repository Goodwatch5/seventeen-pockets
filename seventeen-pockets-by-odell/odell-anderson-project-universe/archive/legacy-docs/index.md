# Legacy Documentation Archive

This folder holds documentation files that were previously in the repository root.

They were moved here on 2026-05-28 as part of the fake-build cleanup pass for the Seventeen Pockets ecosystem. The content has not been altered.

## Why they were moved

These files accumulated in the repository root over time. Many describe phases of work, planned features, or process notes that may or may not still reflect current code. Keeping them at the root made it hard to tell which docs are current and which are historical.

For current docs, check the main `README.md`, `RIGHTWAY_QUICKSTART.md`, and the `docs/` folder. Anything not referenced from those is historical.

## What to do with a file in here

1. If the file still describes how the code works today, move it to `docs/` and link it from the main `README.md`.
2. If it is historical and no longer accurate, leave it here for context.
3. If it is wrong and misleading, edit it with a clear `> Status: superseded YYYY-MM-DD` note at the top instead of deleting it.

Do not silently delete files from this folder. Keep history honest.
